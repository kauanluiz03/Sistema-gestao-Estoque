# 📦 Sistema de Gestão de Estoque

Sistema desenvolvido em Java com o objetivo de realizar o gerenciamento de produtos e operações relacionadas a um estoque.

## 🎯 Objetivo

O projeto foi desenvolvido como forma de praticar conceitos de programação, organização de sistemas e desenvolvimento de aplicações em Java.

## 🛠️ Tecnologias

- Java
- JavaFX
- Programação Orientada a Objetos

## 📋 Funcionalidades

- Cadastro de produtos
- Consulta de produtos
- Atualização de informações
- Exclusão de produtos
- Gerenciamento de estoque

## 📚 Conceitos praticados

- Classes e objetos
- Encapsulamento
- Métodos
- Estruturação de aplicações
- Programação Orientada a Objetos

## 🚀 Como executar

1. Clone este repositório.
2. Abra o projeto em uma IDE compatível com Java.
3. Configure o ambiente Java.
4. Execute a aplicação.
